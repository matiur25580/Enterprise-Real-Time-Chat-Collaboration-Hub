# Real-Time Chat & Collaboration Hub — Screenshot Guide

This folder is reserved for **real screenshots captured from this repository's running application**.

## Required captures

1. **Login / registration screen** — save as `01-home.png`.
2. **Chat workspace with sidebar and conversation** — save as `02-workspace.png`.
3. **Online users and message history** — save as `03-details.png`.

## Capture rules

- Capture the actual running application; do not use generated mockups, stock images, or screenshots from another project.
- Use a consistent desktop viewport (recommended: 1440 × 900) and capture mobile separately only when useful.
- Use synthetic demo data. Remove names, email addresses, tokens, API keys, OTPs, private messages, and other personal or secret data.
- Keep the original screenshot unedited apart from cropping browser chrome if needed.
- Commit the images in this folder, then link them from the project README and the Developer Portfolio gallery.

## Current status

Run the frontend and backend locally with a dedicated test database and two synthetic test users. Use only fabricated messages and accounts.

**No screenshot files are included yet.** This guide deliberately avoids placeholder images so the gallery cannot imply that an unbuilt or unverified screen exists.
